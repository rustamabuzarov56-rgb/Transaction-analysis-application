# Приложение для анализа транзакций

## Описание
Проект предназначен для анализа финансовых операций пользователей банка. Включает инструменты для фильтрации данных, расчета общих сумм расходов, кешбека, курсов валют и стоимости акций.

## Установка зависимостей
Для запуска проекта убедитесь, что установлены необходимые библиотеки Python. Используйте следующую команду для установки:
poetry install pandas, requests 
Также потребуется API key для сервиса Alpha Vantage, доступный по ссылке: https://www.alphavantage.co/support/#api-key##
